# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, welcome newcomers, and keep
criticism about the code, never the person. Harassment, personal attacks and
discriminatory language aren't tolerated, in issues, pull requests,
discussions or anywhere else the project lives.

## Reporting

If someone's behaviour worries you, contact the maintainer,
[@Romainlg29](https://github.com/Romainlg29), privately through the contact
details on their GitHub profile, or use GitHub's **Report content** on the
comment itself. Reports are kept confidential.

The maintainer may edit or remove comments, close threads, and block anyone
who breaks this code, as the Covenant's enforcement guidelines describe.

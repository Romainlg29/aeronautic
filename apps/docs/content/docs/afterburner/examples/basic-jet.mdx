<Example name="basic-jet" />

One nozzle, the `afterburner` preset, and a throttle in React state. The throttle runs to 1.1: up to 1 is dry thrust, past it the burner lights. Drag it back below 1 and the burner goes out: a dry engine's exhaust is too cool to see, and only the turbine glows dull red up the nozzle, so orbit round behind it to see that.

## The stage

Every example on these pages shares this canvas: a `WebGPURenderer`, bloom,
AgX tone mapping, an orbit camera, and a frame loop that only runs while the
example is on screen. `Nozzle` is a bare engine can with its exit at the
origin.
